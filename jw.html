Lingo Captions: kabijakan privasi

Pungkasan dianyari: 13 November 2026

Lingo Captions ngowahi wicara dadi teks, transkrip, lan terjemahan ing piranti Sampeyan dhéwé. Aplikasi iki ora duwé akun, iklan, utawa analitik dhéwé, lan pangembang ora nampa audio, teks, utawa gambar Sampeyan.

Apa sing tetep ana ing piranti Sampeyan

  • Rekaman, teks, transkrip, terjemahan, tembung sing disimpen, kamus, lan setelan Sampeyan disimpen ing panyimpenan kagungané aplikasi ing piranti Sampeyan.
  • Sampeyan bisa mbusak percakapan, bareng transkrip lan rekamané, saka piranti Sampeyan ing Riwayat kapan wae. Yen aplikasi dibusak, kabèh sing disimpen ing piranti Sampeyan uga kabusak.
  • Mikropon mung dipakai nalika Sampeyan mbukak teks, dikte, utawa rekaman, lan aplikasi nuduhaké kapan lagi ngrungokaké.
  • Rekaman mikropon Sampeyan dhéwé disimpen supaya bisa dirungokaké manèh; Simpen rekaman ing Setelan mateni iki.
  • Ing versi App Store, Google Play, lan Microsoft Store, swara sing dijupuk saka aplikasi liya (teks Sistem, lan teks Kelompok utawa Telpon, sing nyampur karo mikropon) disimpen mung supaya aplikasi bisa nyempurnakaké transkripé lan, ing Windows, ngenali panuturé, lan ora tau diputer manèh. Ing iPhone, iPad, lan Android swara kuwi dibusak sanalika wis dipakai Apiki, lan ing Windows sawisé Apiki lan Kenali Panutur padha wis nggunakaké; yen ora, 24 jam sawisé rekaman rampung, utawa nalika aplikasi pisanan dibukak sawisé iku. Versi Mac App Store nyempurnakaké transkrip dhéwé nalika teks mandheg, banjur mbusak swarané.
  • Mung ing Android 12 lan sing luwih anyar: nalika Sampeyan pindhah menyang telpon anyar nganggo transfer saka piranti menyang piranti sing Sampeyan wiwiti, lan piranti transfer ing telpon kuwi ndukung, kabèh sing disimpen aplikasi melu dipindhah, kajaba model wicara lan model sing maca teks ing gambar, sing ora melu lan bisa diundhuh manèh. Ing Android 10 lan 11 data aplikasi ora dipindhahaké. Data aplikasi ora tau kalebu ing cadhangan cloud Android.
  • Ing iPhone lan iPad, kabèh sing disimpen aplikasi kalebu ing cadhangan iCloud utawa komputer duwèke Sampeyan dhéwé, kaya data aplikasi liyané, kajaba rekaman Sampeyan lan model wicara; model bisa diundhuh manèh sawisé dipulihaké.

Apa sing metu saka piranti Sampeyan, lan kapan

  • Undhuhan sing Sampeyan wiwiti utawa setujoni: model wicara, swara, kamus, lan model sing maca teks ing gambar asalé saka server umum (Hugging Face, GitHub, lan situs saben kamus). Kaya undhuhan liyané, server-server kuwi weruh alamat internet piranti Sampeyan. Aplikasi ora ngirim apa-apa bab Sampeyan utawa isi Sampeyan.
  • Kaping pisan saben dina aplikasi takon marang Hugging Face apa model wicara sing wis Sampeyan undhuh owah, supaya bisa nawakaké nganyari. Kaya undhuhan liyané, server weruh alamat internet piranti Sampeyan lan berkas model endi sing dicek. Sampeyan bisa mateni pengecekan iki ing setelan aplikasi.
  • Mung ing Android: terjemahan lan maca teks ing gambar lan PDF nganggo ML Kit saka Google, sing mlaku ing piranti Sampeyan. Audio, teks, lan gambar Sampeyan tetep ana ing piranti, nanging nalika fitur-fitur iki mlaku, ML Kit ngirim informasi diagnostik menyang Google, kayata angka kinerja, kode kesalahan, versi piranti lan aplikasi, basa sing dipilih kanggo terjemahan, lan pengenal kanggo instalasi aplikasi iki. Dikirim kanthi dienkripsi, lan Google ngomong ora diterusaké marang liyané. Model terjemahan ML Kit diundhuh saka Google. Google njlentrehaké iki ing kéné: Pambukaan data ML Kit.
  • Yen piranti Sampeyan duwé, aplikasi nggunakaké pangenalan wicara, terjemahan, lan fitur teks saka Apple utawa Google ing mode ing piranti. Iku bagéyan saka sistem lan manut kabijakan privasi Apple lan Google.
  • Tautan sing Sampeyan tempelaké: aplikasi ngundhuh media saka situs sing Sampeyan sebutaké, sing weruh panyuwunan kuwi kaya saka browser.
  • Kirim Log (Laporaké masalah), ing aplikasi Windows, Mac, iPhone, lan iPad: mung yen Sampeyan milih. Iki mbukak aplikasi email Sampeyan dhéwé kanthi log mlaku sing anyar dilampirké, lan Sampeyan sing mutusaké arep ngirim apa ora. Log kasebut nyebutaké versi lan piranti sing mlakokaké aplikasi lan apa sing ditindakaké aplikasi, bareng kesalahan apa wae; ora ngemot rekaman utawa transkrip, nanging bisa nyebut jeneng berkas sing Sampeyan bukak. Aplikasi Android ora duwé Kirim Log: Google Play nuduhaké laporan crash marang pangembang (versi aplikasi, piranti, lan ing ngendi ing aplikasi crash kedadéan) saka piranti sing pemiliké nuduhaké data panggunaan lan diagnostik karo Google.
  • Tuku: uji coba gratis lan tuku liwat Google Play, Microsoft Store, utawa App Store. Aplikasi mung ngerti apa versi lengkap wis dituku; rincian pembayaran Sampeyan tetep ana ing toko.

Bocah-bocah

  • Aplikasi ora ngumpulaké informasi pribadi saka sapa waé, kalebu bocah-bocah.

Ngrekam wong liya

  • Wartakna marang wong liya sadurungé Sampeyan ngrekam utawa nggawé teks percakapan karo wong-wong kuwi. Aturané beda-beda saka negara siji menyang negara liyané.

Owah-owahan

  • Yen kabijakan iki owah, versi anyar dipacak ing kaca iki bareng tanggalé.
